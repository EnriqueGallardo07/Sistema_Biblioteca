# PBU — Plataforma Bibliotecaria Unificada

Academic collaborative web application focused on library management.

The project was developed as part of a university assignment and includes functionality for user management, book registration, loans, fines, and basic reporting.

## Features

- User registration and authentication
- Role-based access for administrators and users
- User profile management
- Book registration and listing
- Loan registration
- Automatic calculation of loan return dates
- Fine calculation
- Loan reporting
- MySQL relational database integration

## Tech Stack

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- PHP

- MySQL / MariaDB
- phpMyAdmin
